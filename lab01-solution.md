1. *Explain the concept of encapsulation and the way it is implemented in Java*

 **Encapsulation** is often referred to as one of the following:

- bundling together of publicly accessible methods and privately accessible data
- data hiding (controversial, see link below)
- controlled access to the object properties

They are implemented through **Class**.

2. *Explain the following concepts:*

   - *mutator method (setter)*

**Mutator** methods (including *setters*) change the state of an object

   - *accessor method (getter)*

**Accessor** methods (including *getters*) grab the state of an object

3. *Explain two different meanings/roles of:*

   - *this*

The **this** keyword refers to the Class' own private roster of variables.
 
   - *super*

The **super** keyword refers to the inherited Class' own private roster of variables.
